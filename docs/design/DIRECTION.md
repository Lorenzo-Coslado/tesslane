# Tesslane implementation direction

The user selected icon A: “on part sur la a”. They require the silver relief and dark rounded tile. Their reference is Superwhisper's actual macOS application: professional, reassuring, effective, restrained. They explicitly rejected a Docker Desktop / infrastructure-dashboard appearance. The dashboard V2 image is a directional study, not an approved pixel-exact composition.

## Direction contract

- **THESIS:** A calm local workspace makes agent execution legible without competing with the developer's code.
- **OWN-WORLD:** Silver sculptural app icon, charcoal tonal surfaces, compact colored navigation symbols, native-feeling controls and system typography.
- **STORY:** Feature intention becomes a small delivery plan; the developer can inspect agents, decisions, changes and evidence without losing scope.
- **FIRST VIEWPORT:** Narrow rail, project/feature navigation, one useful work surface, and an explicit-recipient conversation panel. Execution state and sample provenance are visible.
- **FORM:** User-pinned direction; no randomized concept tournament. Product UI is code-led. Preserve the approved raster icon; graph and Git content render from live records.

## Quality bar

Use the actual Superwhisper macOS screenshots as the material and density reference, rather than its marketing website. Source captures used during exploration are in `/private/tmp/tesslane-superwhisper-references/` for this development session. The durable source links are in GENERATION-v2.md.

Surfaces should read as familiar macOS application chrome: narrow navigation, gray selection, hairline dividers, modest corner radii, compact readable type, and relief reserved for the icon and small controls. A graph should remain a work surface, with labels, statuses, keyboard focus and inspecting controls. The user requested desktop PCs only; check normal desktop and narrower laptop widths. Mobile is outside the product scope.
