# Code of Conduct

Tesslane welcomes contributors of all backgrounds and experience levels. Treat people with respect, give constructive feedback about the work and make room for different perspectives.

Harassment, threats, discriminatory language, sexual harassment, deliberate disruption, impersonation and publishing another person's private information are unacceptable in issues, pull requests, discussions and other project spaces.

Maintainers may edit or remove harmful content, close or lock a discussion, or restrict participation. Enforcement decisions should be proportionate to the behavior and protect affected participants.

Report ordinary moderation concerns to the maintainer through [GitHub](https://github.com/Lorenzo-Coslado). For abuse, threats or private information, use GitHub's **Report content** or **Report abuse** controls so the report reaches GitHub privately. Avoid repeating private details in a public issue. Security vulnerabilities belong in the [security reporting channel](SECURITY.md).
