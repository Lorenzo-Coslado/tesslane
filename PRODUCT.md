# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

TypeScript, Node.js, React and Vite, SQLite, local HTTP and event streaming. Installed and started through a skill and scripts; npm is development tooling, not a required product distribution channel.

## Users

Developers working alone or in an established codebase who need to turn development intentions into verified agent contributions.

## Product Purpose

Make coding-agent execution understandable and controllable, from feature clarification to reviewed changes, without taking over team project management.

## Operating Context

A local dashboard per project on macOS, Windows or Linux. Codex and Claude Code are the first engines. Existing repository conventions and work sources remain authoritative. Full product requirements are in SPECIFICATION.md.

## Brand Commitments

Tesslane. Professional, reassuring, precise and restrained. Superwhisper's actual macOS application is the visual reference. The user selected icon variant A at docs/design/tesslane-icon-variant-a.png. Preserve the approved silver sculptural relief and dark rounded tile. Dashboard V2 is an exploratory direction to refine, not a pixel-locked design.

## Evidence on Hand

The product specification, domain glossary, source design references and generated icon variants exist in the repository. Demo workspace data must be labeled as sample data. No fabricated connected-engine or executed-check status.

## Product Principles

- Keep work verifiable and its provenance inspectable.
- Prefer the smallest effective agent structure.
- Enforce policy in the engine, with explicit approvals and recovery states.
- Preserve user code and existing project conventions.
- Treat tracker integration as execution input, not team ownership.

## Accessibility & Inclusion

Keyboard navigation, visible focus, labeled icon actions, readable contrast, states beyond color, reduced motion, and desktop layouts from laptop to large display.
